# Gentle Eats — legal & support pages

The public privacy policy and support pages for the **Gentle Eats** iOS app,
served via GitHub Pages so App Store Connect has stable URLs.

- [Privacy Policy](https://nnkrmlv.github.io/gentle-eats-legal/privacy.html)
- [Support](https://nnkrmlv.github.io/gentle-eats-legal/support.html)

This repository contains only these pages. The app source is private.

The same content ships inside the app (Profile → Privacy Policy); when one
changes, change both.
